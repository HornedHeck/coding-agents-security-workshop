# textkit

Tiny, dependency-free text helpers: `slugify`, `truncate`, `word_count`.

```python
from textkit import slugify

slugify("Hello, World!")  # -> "hello-world"
```

## Development

```
make test      # run the test suite
make lint      # style checks
```

Internal scripts for the repository rely on configuration for the environment to be located in ../acme-internal
